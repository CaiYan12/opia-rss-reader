> 状态：**grilling-session 已闭合**，执行计划已建立。执行期间复选框状态必须随时同步更新（每完成一步立即勾选，不得攒批）。

## 一、需求确认记录

### 目标

在保留通用 RSS 阅读能力的前提下，为橘鸦 AI 早报提供独立、可配置的阅读页视觉系统。通用主题继续控制应用框架、首页（非橘鸦源）、设置页及普通阅读页；打开橘鸦订阅页或橘鸦文章阅读页时，改用单独选择的「橘鸦定制风格」。首批五种方向：卡片主题式、千禧网页式、波普艺术式、90 年代报刊式、蒸汽梦核式。

### 范围

- 橘鸦源锁定（不可删除/停用/改名）与设置页对应入口收敛。
- 语义解析器：`content:encoded` → 结构化模型（期头/栏目/条目/编号/导语/正文段/链接/图片）。
- 五种风格 × 亮暗双变体（10 套）独立渲染模板，覆盖阅读详情页（正文+背景，工具栏除外）与橘鸦订阅页（风格化期号列表）。
- 风格选择设置入口（主题卡片底部分割线之下，一对自绘 Select）。
- 静默降级回退通用渲染。
- vitest 单测（纯逻辑）+ Playwright（渲染层）+ 用户真机验收分工。
- 测试夹具（脱敏固化 + .gitignore 排除）。
- AGENTS.md 同步。

### 非目标

1. 不做风格编辑器；橘鸦风格只读。
2. 不实现风格图片资源管线（注册接口仅结构化预留扩展位）。
3. 不改变抓取/缓存链路，不新增任何 IPC 通道。
4. Mini 模式不动。
5. 通用主题体系、ThemeEditor、ThemeService 不动。
6. 不为橘鸦以外的源提供任何定制能力。
7. 不升级任何钉死依赖（vite ^7 / plugin-react ^5 / tailwind ^3 / electron-store ^8）。
8. 不提交、不推送、不创建分支（由用户控制）。
9. 不做启动补回迁移（旧数据删过橘鸦源的用户不补回）。

### 精确识别规则

- 唯一判据：`article.sourceId === 'juya-daily'`（`DEFAULT_SOURCE.id`；`addSource` 生成 `src-*` id 不会冲突）。
- 身份随内置默认订阅存在；用户手动添加相同 URL 的源不获得身份。
- 缓存文章与会话恢复天然携带 `sourceId`，`SavedSession` 不变。

### 数据模型

- `Settings` 新增两个可空字段：橘鸦亮侧风格、橘鸦暗侧风格（最终命名实现时定稿，登记于此）。
- 默认值 = 卡片主题式（两侧）；关闭态表达实现时定稿。
- 风格不进 `ThemeTokens` / `ThemeService` / ThemeEditor；独立内置注册表（声明 `colorScheme`、焦点色、背景材质描述等）。

### 设置与持久化行为

- 主题设置卡片内底部、一条分割线之下：「亮色风格 / 暗色风格」两个自绘 Select（复用 `Select.tsx`），选项 = 五风格 + 关闭。**常态显示、`grid-cols-2` 左右分半占位（同「偏好」区样式；2026-08-28 用户反馈后修订：原「按 `themeMode` 显隐」改为常态显示）**。
- 选择即时生效；沿用亮暗隔离（亮侧只列 light 变体，暗侧只列 dark 变体）。
- `themeMode=system` 时按系统亮暗选对应侧变体（复用现有 `theme:system-changed` 链路）。
- 旧数据缺新字段 → `StoreService.getSettings` 既有默认合并机制回填，无专门迁移。
- 橘鸦源行：不渲染删除按钮、停用与改名入口禁用，仅保留默认星标。

### 渲染和降级规则

- 解析时机：渲染进程打开文章时 DOMParser 实时解析；不碰抓取/缓存。
- 整篇降级：关键骨架缺失（无栏目/无条目标题）→ 静默回退现有 ReaderView 渲染，无提示。
- 部分失配：缺导语/编号等 → 模板内缺什么不渲染什么。
- 非橘鸦文章永不进定制路径。
- HomeView：`activeSourceId === 'juya-daily'` 时列表按所选风格渲染，**遵循通用 `layout` 设置（预设/列数/显示字段）**（2026-08-28 用户验收反馈后修订：原「忽略 layout」改为遵循）。

### 五种主题的设计约束

1. **卡片主题式**：保留期头横幅/条目卡片/编号徽章/导语引用块；禁止卡片无层次堆砌。
2. **千禧网页式（Y2K）**：保留像素感边框/渐变按钮/系统字体风/复古链接（↗）；禁止廉价 clipart、闪烁文字。
3. **波普艺术式**：保留高饱和平涂/粗轮廓/网点纹理/大字标题；禁止超过 3 个主色打架、正文可读性让步。
4. **90 年代报刊式**：锚定真实 90 年代中文报刊语言（报头/栏目栏/分栏/题图说明），禁止做成现代 broadsheet hairline 模板、禁止做旧滤镜滥用。
5. **蒸汽梦核式**：保留霓虹渐变/暗色氛围/发光边框/空灵感；禁止动画过载（背景动画每屏 ≤1 处且可关闭）、禁止降低正文对比度。
- 全局底线：统一正文可读性（字号/行高/AA 对比度）；`prefers-reduced-motion` 全动效降级。
- 每风格自绘风格化页面背景（阅读页滚动区 + 订阅页），首版纯 CSS + 内联 SVG，接口为图片资源预留。

### 安全与可访问性要求

- 安全：DOMPurify 策略与链接拦截**保持现状不放宽**；富文本片段走同一份配置；风格全部由 CSS 类承担；模板自绘 `<img>` 带 `loading="lazy"`。
- 可访问性：模板内焦点态用风格自身焦点色（注册时提供，不改全局变量）；正文/标题对比度亮暗各达 WCAG AA；输出保留 heading 层级与 list 语义；动效全部支持 reduced-motion。
- 响应式六条基线（窄窗单列、长标题换行、无图不占位、多图垂直堆叠、30+ 条目滚动流畅且装饰成本可控、未知节点忽略）逐风格验收。
