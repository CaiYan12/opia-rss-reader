# SPEC：90 年代报刊式（newsprint90s）风格优化

**日期**：2026-10-21
**Issue**：[#25](https://github.com/CaiYan12/opia-rss-reader/issues/25)（`ready-for-agent`）
**范围**：仅 `newsprint90s` 的亮侧与暗侧两个变体；八风格中的其余七种不动。
**前置**：只读体检与四轮 grilling 已完成，术语以根目录术语表为准（刊头、概览、版式、导语、栏目、条目、订阅页、阅读页、变体）。

## Problem Statement

当前的「90 年代报刊式」只完成了阅读页的一半：订阅页仍是通用卡片网格，阅读页只有黑底栏目条、双栏与日期线；序号徽章仍是圆胶囊，正文链接是 Web 蓝，段首没有缩进，暗侧次要文字与导语在纸纹上的对比度低于 AA。用户看到的第一屏（订阅页）几乎没有报刊语言，阅读页也缺少报头、纸张质感与排印层级，整体更像「换了颜色的现代卡片界面」，而不是一份 90 年代中文都市报。

## Solution

把订阅页与阅读页都做成一份 90 年代中文都市报：

- **阅读页**：三栏刊头（左日期、中期号标题、右星期）、上细线下双线、楷体报头、黑体标题与栏目条、宋体正文、2em 段首缩进、1px 栏线与黑底栏目条；纸张中度泛黄，叠加纤维与轻暗角；暗侧改为「灯下读报」的暖暗纸；序号徽章改黑底纸字方角；链接改墨色下划线；相关链接做成细线资料条；概览加框线与「导读」小标。
- **订阅页**：头版式。期号标题成为第一视觉；非 magazine 预设用 160px × 4:3 的小图版，magazine 首条保留 3:2 大图；条目用细线分隔而非卡片，hover 改为下划线/纸面微亮；来源改无框小字，未读点改方形；空态改为框线公告。所有预设、列数与显示字段门控继续生效。
- **可达性**：所有文字对「最不利纸纹行」仍 ≥4.5:1；不新增动效；保持焦点环、缩放与减少动态效果行为。

## User Stories

1. 作为读者，我希望刊头左侧显示发布日期、右侧显示星期，这样它读起来像一份真实报纸。
2. 作为读者，我希望期号标题居中并使用楷体，这样刊头具有 90 年代报纸的声音。
3. 作为读者，我希望刊头上方有一条细线、下方有一条双线，这样报头与正文之间有印刷品的层次。
4. 作为窄窗读者，我希望刊头在窄窗回落到居中堆叠，这样 560px 下仍然可读。
5. 作为读者，我希望刊头只显示真实的发布日期与星期，不出现编造的期号或版次。
6. 作为读者，我希望阅读页版心略宽、宽窗保持双栏，这样页面像一张报纸版面而不是窄栏网页。
7. 作为读者，我希望正文段落有 2em 首行缩进、段距收紧，这样段落像印刷品一样被标记。
8. 作为读者，我希望栏目条保持黑底反白并使用黑体，这样栏目标题可以被快速扫读。
9. 作为读者，我希望双栏之间有 1px 栏线，这样两栏像报纸的独立栏位。
10. 作为读者，我希望图片是直角图版，而不是圆角卡片，这样它们与整页的直角语言一致。
11. 作为读者，我希望正文用宋体、标题与栏目条用黑体、刊头用楷体，这样字体层级符合 90 年代报刊。
12. 作为读者，我希望亮侧纸面中度泛黄并带纤维与轻暗角，这样页面像旧报纸而不是纯色背景。
13. 作为暗侧读者，我希望暗色模式像「灯下读报」的暖暗纸，而不是纯黑界面。
14. 作为读者，我希望链接是墨色加下划线、hover 变报刊红，这样链接像印刷批注而不是 Web 蓝字。
15. 作为低视力读者，我希望所有文字在纸纹最不利的一行仍达到 4.5:1，这样材质不会牺牲可读性。
16. 作为读者，我希望序号徽章是黑底纸字的方角标签，这样它与栏目条属于同一套印刷语言。
17. 作为读者，我希望导语以上下细线与正文分开，这样它像报纸的引题或提要。
18. 作为读者，我希望概览被框线包住并带「导读」小标，这样本期要目像报纸的导读栏。
19. 作为读者，我希望相关链接是「上沿细线 + 相关链接小标」的资料条，这样它与正文分开但不变成卡片。
20. 作为键盘读者，我希望焦点环与 hover 反馈保留，这样风格化不会牺牲可操作性。
21. 作为读者，我希望订阅页像报纸头版而不是卡片网格，这样风格从第一屏就成立。
22. 作为读者，我希望期号标题是订阅页的第一视觉，封面缩成 160px × 4:3 的小图版，这样图片不压过标题。
23. 作为使用 magazine 布局的读者，我希望首期保留 3:2 的大图，这样头版仍有一张主照片。
24. 作为读者，我希望订阅条目之间用细线分隔而不是卡片，这样列表像报纸目录。
25. 作为读者，我希望 hover 是下划线或纸面微亮，而不是卡片上浮，这样交互保持印刷感。
26. 作为读者，我希望来源显示为无框小字、未读标记为方形，这样元信息安静且与直角语言一致。
27. 作为读者，我希望空态是带上下细线的公告，而不是一行灰字，这样无内容状态仍然是设计过的。
28. 作为使用紧凑列表的读者，我希望保留小缩略图但改为直角，这样预设不会被风格覆盖。
29. 作为使用网格布局的读者，我希望列数设置继续生效，这样风格不会改变我的布局选择。
30. 作为关闭封面字段的读者，我希望订阅页不再显示封面，这样显示字段门控继续生效。
31. 作为 480/560px 窄窗读者，我希望页面没有横向滚动，这样风格在窄窗仍可用。
32. 作为用户，我希望亮/暗两个变体与跟随系统模式都能取到正确的一侧。
33. 作为用户，我希望内容区缩放后刊头与双栏仍然可用，不被放大破坏。
34. 作为用户，我希望减少动态效果设置继续生效，并且本轮不新增动画。
35. 作为用户，我希望其他订阅源、其他七个风格与既有功能不受影响。
36. 作为维护者，我希望对比度与形状（方角、字体栈、缩进）有静态守卫，未来改动不会静默回退。
37. 作为维护者，我希望测试只断言可见行为与计算样式，而不锁死具体 CSS 规则文本。
38. 作为维护者，我希望本轮不新增截图归档基线，但仍保留可核对的前后对比图。
39. 作为维护者，我希望本轮不修改共享层；若确实受阻，先回报再决定。
40. 作为读者，我希望所有术语在规格与界面中一致：刊头、概览、版式、导语、栏目、条目。

## Implementation Decisions

**范围与结构**

- 只修改橘鸦样式表中的 `newsprint90s` 作用域与 `newsprint90s` 模板；共享层（模板工厂、订阅页骨架、语义构件）不改。
- 为 newsprint90s 写一个自定义阅读页模板：刊头三栏与带「导读」标签的概览需要真实 DOM，不能靠伪元素。订阅页继续使用工厂生成的列表，仅通过样式重塑。
- 阅读页模板复用既有的语义构件（概览、条目块、链接拦截），不复制解析逻辑，也不改变安全边界。
- 变体覆盖一律使用「变体属性 + 风格类」的复合选择器形态；禁止使用带空格的后代形态。

**刊头与版式**

- 版心：阅读页容器上限 800，内容宽 752，双栏每栏约 362；宽窗 ≥900 开双栏，窄窗单栏。
- 刊头：左日期、中期号标题、右星期，全部来自真实字段；宽窗 38px / 6px 字距，窄窗 30px / 4px；上 1px 细线、下 4px 双线；日期与星期 11px 宋体、字距 1px。
- 栏目条保持黑底反白，不加下沿线；栏线 1px；正文段首 2em 缩进，段距收紧。
- 序号徽章改为标题色底、纸色字的方角标签；不再使用 accent 底。
- 导语保留上下细线与浅底，文字改用重算后的次要文字色。
- 相关链接改为上沿 1px 细线 + 「相关链接」小标 + 墨色链接。

**字体与颜色**

- 字体：刊头 KaiTi/STKaiti；标题、栏目条 SimHei/Noto Sans SC；正文 SimSun/Noto Serif SC。全部为系统字体栈，不打包字体文件。
- 亮侧：纸 `#ece2c6`、卡片 `#f0e7cf`、正文 `#33301f`、标题 `#211d14`、次要文字 `#5f5747`、链接墨色 `#2b2620`、accent `#8b1a1a`。
- 暗侧：纸 `#1e1913`、卡片 `#262019`、正文 `#d6cbb2`、标题 `#efe6cf`、次要文字 `#a2997b`、accent `#d05555`、链接 `#9fb4e8`。
- 次要文字一个 token 同时覆盖导语：亮侧对纸纹 5.09、对卡片 5.79、对导语底 4.55；暗侧 5.65 / 5.66 / 4.98（初版写错：曾写 5.24 / 4.65、5.73 / 5.04；以守卫「全纹理层叠最不利行」实算为准）。
- 暗侧 accent 对新纸底的对比约 4.25，只用于未读点等非文本件；徽章不再依赖 accent 底。
- 纸张质感：3px 横纹 + 纤维噪点 + 极轻暗角，全部为背景层；不使用会作用于文字的滤镜。
- 链接：墨色 + 常驻下划线；hover 使用 accent 红；焦点环颜色不变。
- 滚动条字面色沿用现有字面色，但注释中的旧对比度必须按新纸色更新。

**订阅页**

- 去卡片化：条目不再有卡片底色、边框与阴影，改用细线分隔。
- card/grid 预设：封面为 160px × 4:3 图版，与标题/摘要并排；标题 18px 黑体；无封面时标题独占整行。
- compact 预设：保留小缩略图但改直角，标题 14px；不改变行式结构。
- magazine 预设：首条封面 3:2，标题 26px；其余条目回到 card 形态。
- hover：下划线/纸面微亮，去掉卡片上浮位移；减少动态效果下不新增过渡。
- 来源：无框小字，与日期同一行；未读点 4px 方形。
- 空态：上下 1px 细线的公告框，黑体「暂无内容」+ 小字刷新提示。
- 所有预设、列数与显示字段门控继续生效；风格不覆盖通用布局设置。

**交互与系统**

- 不新增动画；保留基础列表入场动画。
- 亮/暗由现有变体机制决定；跟随系统、缩放、减少动态效果、不可见暂停均不改。
- 不新增 IPC、数据结构或持久化字段；不修改插件契约。

## Testing Decisions

**好测试的标准**

- 只断言用户可见的结构、布局关系与计算样式，不断言具体 CSS 规则文本、选择器写法或内部变量。
- 对比度以「纸纹最不利行」为口径，而不是纯色 token；静态守卫可以用解析式计算，但必须把纹理叠加算进去。
- 结构断言用稳定的语义类与相对位置（左 < 中 < 右、窄窗堆叠），不用像素魔法数。

**缝合点（沿用既有，不新增）**

1. **端到端渲染（最高缝合点）**：使用既有 `newsprint` 场景驱动真实渲染，新增/扩写用例覆盖：
   - 亮/暗 × 1280 的刊头三栏相对位置与真实日期/星期；
   - ≤900 的刊头堆叠与 560/480 无横向溢出；
   - 概览「导读」标签可见、框线存在；
   - 徽章方角、相关链接资料条、链接墨色下划线；
   - 订阅页 card/grid/compact/magazine 四态的图版尺寸与标题层级；
   - 空态公告框；
   - 封面显示字段关闭时无封面；
   - hover 不再上浮（计算样式不再产生位移）。
2. **CSS 静态守卫（既有单测缝合点）**：新增 newsprint 组，覆盖：
   - 无「变体属性 + 空格 + 风格类」死形态；
   - 亮/暗次要文字与导语在最不利纸纹行 ≥4.5；
   - 徽章与来源不使用 999px 胶囊；
   - 字体栈包含 KaiTi / SimHei / SimSun 且顺序正确；
   - 链接为墨色而非蓝色；
   - 段首 2em；
   - 订阅页 hover 不含上浮位移；
   - 纸色与 accent 取值落在本轮决定的集合内。

**先例**

- 既有 newsprint 阅读页/订阅页端到端用例；
- folio 的 muted 对比度静态守卫；
- nocturne 的几何与对比度用例；
- 全量验证命令 `npm run verify`。

**回归**

- 现有用例只在与 DOM 结构变化直接相关处更新（刊头日期行的结构），并保留稳定语义类；不做无关修改。
- 其他七个风格、非橘鸦来源、Mini、缩放、会话恢复的既有用例必须继续通过。
- 本轮不新增归档基线；改前/改后对比图作为人工证据附在交付说明中。

## Out of Scope

- 共享层（模板工厂、订阅页骨架、语义构件）的修改；如确实受阻，先回报再决定。
- 其余七个风格的任何样式或结构改动。
- 新增截图归档基线（归入 /retro ④）。
- 新增动画、纸片动效或翻页转场。
- 编造期号、版次、记者等无真实来源的字段。
- 重做双栏图文流（宽窗多图导致的栏底参差是已实测的已知取舍）。
- Mini 模式的报刊化（橘鸦风格本就不作用于 Mini）。
- IPC、数据结构、插件契约、CI 与远端推送。

## Further Notes

- **已知取舍**：宽窗双栏 + 短文本 + 多图时，栏底会出现参差；1280 下最坏实测 190.6px。整组避断、图文 grid、有图条目单栏三种替代方案实测更差，本轮保留现状并记录。
- **术语**：本轮统一使用「刊头」（不写「报头」）；「概览」是域术语，界面小标题「导读」只是文案；「版式」指整体版面构造，「布局」只指通用列表配置；「降级」与「回退」分开使用。
- **对比度口径**：所有文字对纸纹最不利行计算；亮侧次要文字 5.09 / 5.79 / 4.55，暗侧 5.65 / 5.66 / 4.98（初版写错的 5.24 / 4.65、5.73 / 5.04 已按守卫实算更正）。
- **视觉验收**：改前/改后各出亮/暗、阅读页/订阅页、1280/900/560 的对比图；不声称未在真机窗口验证的项。用户已于 2026-10-22 真机验收并确认效果满意。
- **发布**：已发布为 issue #25（`ready-for-agent`）；父 issue 保持发布时正文、未在收口后修改。本文件的数值与下方「收口校正」为最终口径。

## 收口校正（2026-10-22）

- 刊头堆叠断点由 ≤900 收成 **≤899**，与双栏 ≥900 互斥；900px 时三栏刊头与双栏同时成立，实测 752 版心不溢出。
- 空态拆成真实 `strong`（暂无内容，15px 黑体）+ `span`（点击右上角刷新获取，12px muted）；由 newsprint 模板的空态 FeedList 渲染，共享骨架未改。
- 链接：概览与相关链接常驻下划线；概览 / 相关链接 / 条目标题 hover 转 accent。条目标题链接不加常驻下划线，是报刊标题的故意例外。
- 订阅页 hover 改用中性 `--jy-feed-hover`，不再借用 accent 红洗；暗侧 muted 对 hover 面实测 4.97，亮侧 4.71。
- 字体全部走 token（新增 `--jy-font-masthead`），规则不再写死字面栈。
- 静态守卫：本仓既有的 `juyaCssGuard` 是既定验证 seam，会读取 CSS 取值；本 SPEC 的「不断言规则文本」约束行为 / 渲染测试，不废除静态守卫。已删除仅锁 JSX 源码写法的正则守卫。
- 双轴 code review 后 `npm run verify` 仍 exit 0（vitest 481 / Playwright 119 / nocturne 归档 5 张逐字节一致）。
- 完整前后矩阵：`screenshots/newsprint-audit/before-full|after-full`（亮/暗 × 阅读/订阅 × 1280/900/560；gitignored）。
- 刻意未改：自定义 IssueView 复刻工厂 section/entry 映射、订阅页三态 CSS 重复、`base.tsx` 的 `mastheadExtra` 遗留；均属「共享层零改动」的取舍。
- `GLOSSARY.md` 是用户单独指令，不属于本 SPEC 的票据范围。
