# SPEC：杂志编辑式（editorial）风格完善

**日期**：2026-10-22  
**状态**：设计共识已确认；#50–#55 实施与验收已全部合入本地 `codex/editorial`；独立双轴评审已完成且无阻断，收口记录见 `out/editorial-implementation-2026-10-22/55-report.md`；父票 #49 保持 OPEN，等待用户选择后续发布／封稿。本状态不代表用户已封稿或已发布。
**基线**：`main`，`bfcf32928481a805f5c5f45bde26f5607d60d062`。  
**范围**：editorial 的亮暗两侧、阅读页与订阅页。图片放大、灯箱及新增图片链接交互明确排除。

## Problem Statement

> **改造前基线**：以下问题陈述描述 #50–#54 实施前的状态，作为需求来源保留；当前完成与验收状态见文末 #55 收口记录。

读者选择杂志编辑式后，能够看到衬线刊头、细线、暖色纸面与砖红强调色，但长篇期号仍主要依赖固定版式：每栏目首条的全部正文挤在左半栏，全部图片堆在右半栏，无法适应文字与图片数量、比例的变化。长摘要与单列概览又拉长了进入正文前的距离。订阅页主要沿用通用卡片，杂志编辑式的辨识度不足。

2026-10-22 体检使用真实当日期号（6 个栏目、32 条目、34 张正文图），并补充离线合成样本，确认以下改造前事实：

- 在 1280px 窗宽、100% 内容区缩放下，真实首条正文列约宽 398px、高 669px，右侧图列约高 184px。固定分栏造成正文偏窄、图列下方留白较大。
- 每栏目首图被强制裁成 21:9。真实样本中有 1080×1184 的竖图，显示窗口却约为 374×160，不能完整展示资讯截图。
- 摘要约高 154px，32 条概览单列约高 826px，首条正文从页面约 1376px 处开始。首屏并非必须出现正文，但目前的铺陈缺少适合长概览的组织。
- 641px 窗宽、120% 内容区缩放下仍命中双栏，合成样本的正文列约宽 267px；原有视口断点不能充分表达实际可用阅读宽度。
- 暗侧 12px 序号徽章文字与底色对比度为 3.8354:1；22px、400 字重的栏目序号对底色为 3.8800:1，低于相应的小文本 AA 门槛 4.5:1。这两项是平涂 token 实算，未将其冒称为全纹理背景审计结果。
- 减少动态效果下，正文图片悬停仍放大 2%，过渡时间被压成近乎瞬时变化。
- 刊头使用本地化日期，刊尾直接截取 UTC 日期。北京时间下，发布时间 `2026-10-21T17:00:00.000Z` 会分别显示 10 月 22 日与 10 月 21 日；当前上午发布的真实期号未触发此边界。

这些事实不意味着现有功能全部失效。体检已确认实际字体落在 Noto Serif SC／Noto Sans SC 等现有字体上；所查矩阵无横向溢出，键盘焦点与文字外链分流可用，三种订阅布局、网格字段隐藏及空态已有实现。

## Solution

将杂志编辑式完善为当代中文科技／文化杂志的阅读呈现：米白与暖黑纸面、砖红强调色、衬线标题与无衬线正文保持同一视觉身份，主要通过标题层级、细线、图片尺度与留白建立节奏。

阅读页保留有辨识度的开篇，后续正文回到连续阅读列。正文图片按原比例完整展示，首图可以参与开篇构图，其余图片随文出现。摘要改为左对齐正体，概览在宽窗分为两列、窄窗回到一列，保留全部条目与原顺序，不默认折叠。

订阅页以封面、细线、日期和留白组织期号，去掉整卡外框与悬停上浮，继续遵循既有布局设置。亮暗两侧分别校准可读性与对比度，日期线与刊尾使用一致的日期口径。

本轮只完善风格的呈现与适配。正文图片仍维持当前交互，不加入放大、灯箱、图片链接恢复或其他图片操作。

## User Stories

1. 作为读者，我希望亮侧与暗侧都具有当代中文科技／文化杂志的气质，以便切换外观后仍能辨认同一风格。
2. 作为读者，我希望刊头、栏目条、条目标题和正文有明确层级，以便快速定位阅读位置。
3. 作为读者，我希望保留现有米白／暖黑与砖红语言，以便风格完善后仍延续当前视觉身份。
4. 作为读者，我希望摘要左对齐、使用正体，以便连续阅读较长的中文摘要。
5. 作为读者，我希望长概览在宽窗合理分列，以便更快扫读本期内容。
6. 作为读者，我希望窄窗中的概览回到一列，以便每条标题有足够宽度。
7. 作为读者，我希望概览保留全部条目、编号和原顺序，以便不因视觉改造遗漏内容。
8. 作为读者，我希望每栏目首条具有开篇层次，以便栏目之间有清楚的阅读节奏。
9. 作为读者，我希望首条的后续正文回到连续阅读列，以便长文不一直挤在图片旁边。
10. 作为读者，我希望竖图和窄窗采用上下排列，以便图片比例和文字宽度都得到尊重。
11. 作为读者，我希望正文图片完整展示，以便资讯截图里的文字、图表和界面信息不被强制裁掉。
12. 作为读者，我希望开篇首图以外的图片随正文出现，以便图文关系接近原文。
13. 作为读者，我希望每张图片和每段正文只出现一次，以便没有重复、遗漏或顺序混乱。
14. 作为读者，我希望无图、无导语或无摘要的内容仍自然成版，以便缺少可选内容时不留下空栏与空装饰。
15. 作为读者，我希望长标题、长链接和多图内容都能正常折行与排布，以便窗口变窄后仍能读全。
16. 作为读者，我希望首字下沉不再出现在每一条短导语中，以便强调有节制，正文保持平稳。
17. 作为读者，我希望暗侧的小编号、栏目序号及次要文字清晰可辨，以便低亮度阅读时不丢失信息。
18. 作为读者，我希望刊头日期线与刊尾显示同一个发布日，以便跨日时间不会产生矛盾。
19. 作为读者，我希望订阅页通过封面、细线与留白体现杂志感，以便它与阅读页具有连贯的视觉语言。
20. 作为读者，我希望紧凑列表、卡片网格和杂志风三种布局继续可用，以便保留自己的浏览习惯。
21. 作为读者，我希望已有列数和显示字段设置保持其原有语义，以便风格更新不会改变我的偏好。
22. 作为读者，我希望空订阅页与无封面期号仍有完整呈现，以便内容缺失时仍看得懂页面。
23. 作为读者，我希望点击期号、标记已读和收藏过滤等行为保持原样，以便外观更新不打断使用流程。
24. 作为键盘用户，我希望期号与文字链接仍有清楚的焦点反馈，以便不依赖鼠标完成阅读。
25. 作为读者，我希望概览、条目标题和相关链接继续遵循外链设置，以便打开位置与当前偏好一致。
26. 作为读者，我希望悬停反馈不让卡片或图片移动、放大，以便阅读位置保持稳定。
27. 作为选择减少动态效果的读者，我希望相应状态保持静态，以便不会遇到瞬时缩放或入场位移。
28. 作为读者，我希望调节内容区缩放后版式仍适配，以便放大文字时不被困在过窄的半栏。
29. 作为读者，我希望图片本轮只改变展示方式，以便没有未经本轮范围确认的新点击或放大行为。
30. 作为使用其他风格或通用阅读路径的读者，我希望自己的界面不受 editorial 更新影响，以便各风格保持独立。

## Implementation Decisions

### 范围与架构

- 只完善 `editorial-light` 与 `editorial-dark`。风格 id、变体 id、亮暗选择与跟随系统的解析方式保持现状。
- 改动集中在 editorial 模板的 `IssueView`、`FeedList` 及其作用域样式。需要新的图文组合时，在该风格内部组合既有语义构件，不改变其他风格共用构件的默认行为。
- 使用现有 `JuyaIssue`、`JuyaEntry.blocks`、图片、布局与历史状态。无需修改结构化解析契约、文章缓存、订阅源提供方、持久化字段或 IPC 契约。
- 不新增渲染进程取数或文件访问；仍消费既有数据流。图片沿用当前来源和懒加载方式。
- 变体专属覆盖继续使用变体属性与 `.jyedit` 同根的复合选择器。普通 editorial 覆盖也必须限定在本风格作用域内，禁止修改全局规则来实现局部外观。

### 视觉基础

- 保留米白／暖黑底、砖红强调色与现有衬线标题／无衬线正文的字体组合，不引入在线字体请求、字体文件或依赖升级。
- 以现有版心、字号和间距为起点，调整刊头、栏目条、条目标题、摘要、正文与元信息之间的层级。不改变全局基准字号、全局主题或内容区缩放机制。
- 通过细线、图片尺度和留白组织版面，不新增场景动画、毛玻璃或另一套装饰系统。
- 修复暗侧序号徽章和栏目序号的对比度。具体颜色不预填未经测量的值：保持砖红色相方向，在实际背景下满足验收门槛后确定，并记录最终取值与测量结果。
- 日期线、摘要、导语、题注、相关链接标签及刊尾等次要文字也须检查实际出现背景；不能只让两处编号通过而忽略其余文字。
- 首字下沉不再应用于所有导语。将其限制在栏目首条的开篇导语，其余导语使用正常排字；首条缺少导语时不补造内容。中文、英文及引号开头的样本均须检查，不得出现遮字或异常挤压。

### 刊头、摘要与概览

- 刊头继续显示真实期头，缺失时沿用文章标题回退，不新增虚构期号、作者或编辑信息。
- 摘要使用左对齐正体，不因改版另行截断、改写或默认折叠；没有摘要时不保留空块。
- 概览宽窗两列、窄窗一列，保留全部条目、编号、文字与原顺序。视觉阅读顺序、DOM 顺序和键盘顺序须一致，不能以视觉重排制造跳读。
- 沿用现有概览外链含义，不改成正文内跳转，不新增展开／收起控件。
- 不将「正文必须出现在首屏」设为验收目标，也不通过隐藏摘要或概览来缩短首屏。使用相同内容、视口与字号时，宽窗长概览应较当前单列缩短纵向占用。
- 刊头日期线与刊尾均以同一发布时间、同一现有本地时区口径派生日期；允许文字格式不同，但日历日期必须一致。不新增时区设置，不修改缓存中的 UTC 时间。

### 阅读页图文组织

- 每栏目首条的标题、导语与主图组成开篇；首图为横图且可用阅读宽度充足时采用图文并排，但后续正文必须退出该分栏，与非首条使用同一连续正文列。
- 竖图、窄窗或内容区缩放使开篇可用宽度不足时，改为上下排列。不能继续仅依赖原 640px 视口断点；641px 窗宽、120% 缩放是必须覆盖的上下排列回归点。
- 栏目首条有图时，将首张正文图提升到开篇，提升后从后续内容流中排除该张图，避免重复。除此之外，剩余段落与图片按现有 `blocks` 顺序呈现。
- 非首条按现有内容流顺序呈现段落与图片，不再固定为「所有段落之后堆所有图片」。相关链接仍位于所属条目末尾。
- 所有正文图片保持原比例、完整可见，不使用 21:9 等固定窗口裁掉内容，不拉伸图片，不用图片遮罩隐藏边缘。允许限定最大展示宽度，但须保留完整画面。
- 订阅页封面属于缩略呈现，与正文图片分开处理；不把正文图完整展示的要求扩展为重写所有封面裁切规则。
- 保留已有替代文本与题注来源，不为无题注图片编造说明。图片本身不增加按钮角色、焦点入口、放大指针、点击处理或链接包裹。
- 无图时不生成空图列；无导语、无编号或无相关链接时不生成对应空占位。不得删减正文以平衡列高。

### 订阅页

- 去掉包围整条期号的卡片外框与悬停上浮，使用封面、细线、日期、标题层级和留白形成期号之间的分隔。
- 沿用 `FeedShell` 的预设分发与 `feedFieldGates` 的字段门控。可以使用风格内的期号呈现，但不复制另一套布局或已读／收藏状态逻辑。
- 保留现有字段语义：普通网格遵循显示字段；紧凑列表不显示摘要；杂志风首条 `featured` 既有的封面与摘要优先展示规则保持原样。不能把本轮变成修改该共享规则的功能更新。
- 保留已配置列数、期号顺序、点击打开阅读标签、已读状态与收藏过滤。无封面、少内容和空列表须自然成版。
- 空态继续表达当前刷新引导，不新增交互流程或改写为另一种空状态功能。

### 交互与动效边界

- 文字链接继续使用现有安全出口与外链设置，键盘可达性不变；焦点反馈不得被去外框或新的装饰线遮盖。
- 图片点击保持 editorial 当前行为。既不加入裸图放大，也不开始消费图片链接字段；图片链接语义的恢复属于独立功能更新。
- 正文图片不再悬停缩放，期号不再悬停位移。悬停反馈可以改变颜色或下划线，不新增几何位移。
- 减少动态效果下无图片缩放、卡片位移或入场位移；不能只把过渡时间缩短后保留最终放大状态。

## Testing Decisions

### 已确认的测试边界

沿用 Q9 已确认的「风格专属行为／几何／对比度测试 + 前后截图 + 真实 Electron 验收，暂不新增逐字节归档」。主要入口选择现有渲染层 E2E，在同一个可见页面上测试读者可观察的结果；仅以少量现有样式／对比度守卫补足作用域与颜色约束，不新增测试框架或 IPC 测试入口。

好测试应当检查内容是否完整、实际位置与图片比例、焦点是否可见、点击后打开什么，以及真实背景上的可读性。不能只确认根节点有 `.jyedit`，也不能把某条 CSS 正则命中当成实际版式通过。

### 复用的测试先例

- 阅读页／订阅页现有渲染 E2E 与 `window.opia` 内存桩：继续使用现有场景注入方式，并将断言限定在活动标签内容容器内。
- newsprint90s 的多视口、刊头、概览与三种订阅布局验证：复用几何和计算样式的验证方式。
- 现有可渲染内联 SVG 场景：为横图、竖图、多图和图文交错创建确定性样本，避免依赖坏链塌陷后的假几何。
- 现有样式守卫、对比度计算及滚动条守卫：扩展 editorial 覆盖；纯计算复用现有口径，避免另写一套相互漂移的公式。
- 现有五张 nocturne 归档仍是回归闸门，不将它们冒充为其他全部风格的逐字节证明。
