# SPEC：蒸汽梦核式（synthwave）风格重构

**日期**：2026-10-22
**状态**：已发布 [#34](https://github.com/CaiYan12/opia-rss-reader/issues/34)
**前序**：本轮已完成 audit + grilling；`dreamcore → synthwave` 改名已实施（未提交）

## Problem Statement

用户选择「蒸汽梦核式」时，得到的和这个名字承诺的不一样。

阅读页只有一个被卡片盖住的模糊圆盘、一堆半透明卡片和一片纯黑底：代码里写的「条纹太阳 + 透视霓虹网格」，网格在 620–1440px 五档窗高下**全部落在视口之外**（visiblePx −69.5 … −33.9），地平线辉光随之一起消失；太阳压在概览列表上，暗侧概览文字对落日的对比度只有 1.33–1.88。订阅页完全没有场景，只剩淡紫底与通用卡片。亮侧是低饱和淡紫，与合成波夜景毫无关系。

用户无法从这个风格里看出「落日、霓虹地面、CRT 夜空」这套语言，也就没有理由选它，而不是其他七个已经逐轮打磨过的风格。

## Solution

用户进入蒸汽梦核式的阅读页时，看到的是一幅合成波夜景：紫→洋红→橙的夜空、极淡的扫描线、居中的条纹落日，以及从画面底缘向地平线收拢的霓虹网格。正文仍然落在毛玻璃卡片上，概览有独立底板，读得清；订阅页共享同一套场景；亮侧是同一母题的日间版——洋红橙高饱和，卡片同为毛玻璃。风格 id 改为 `synthwave`，界面名仍叫「蒸汽梦核式」。

## User Stories

1. 作为读者，我希望打开蒸汽梦核式的文章时看到条纹落日，以便这个风格真的像合成波海报，而不是紫色卡片堆。
2. 作为读者，我希望地平线以下的透视网格真实可见，以便画面有「地面」而不是悬空的卡片。
3. 作为读者，我希望网格从画面底缘向地平线收拢，以便获得参考图那种纵深。
4. 作为读者，我希望天空是紫→洋红→橙的垂直渐变，以便夜空有层次而不是一块纯色。
5. 作为读者，我希望画面上覆盖极淡的水平扫描线，以便有 CRT 质感，但字不被横纹干扰。
6. 作为读者，我希望概览列表有自己的底板，以便它压在落日上时仍然读得清。
7. 作为读者，我希望正文卡片是毛玻璃而不是实底，以便场景能从卡面后透出来。
8. 作为读者，我希望毛玻璃在滚动时保持稳定，以便不出现闪烁或边缘错位。
9. 作为读者，我希望刊头标题有金属渐变与细描边，以便它有海报标题的量感。
10. 作为读者，我希望相关链接的箭头是一个图标而不是字符，以便它与其它图标元素对齐。
11. 作为读者，我希望订阅页也有同一套场景，以便从列表进入文章时不会掉回通用外观。
12. 作为读者，我希望订阅页的日期与来源前有图标，以便一眼分辨元信息。
13. 作为读者，我希望条目配图有霓虹描边和轻微降饱和，以便照片与卡片语言一致。
14. 作为读者，我希望亮侧也是高饱和洋红橙，以便白天开启时仍是同一风格，而不是另一套淡紫配色。
15. 作为读者，我希望亮侧正文仍然清晰，以便高饱和不等于看不清。
16. 作为读者，我希望悬停反馈只是发光加深，以便长列表不因卡片位移而晃动。
17. 作为读者，我希望窗口最小化后场景动画停止，以便不白白耗电。
18. 作为读者，我希望开启「减少动态效果」时落日与网格静止，以便不因动画产生不适。
19. 作为读者，我希望窄窗（560px）下场景仍然成立，以便小窗口也有同一构图。
20. 作为读者，我希望关闭该风格时干净地回到通用阅读页，以便不喜欢时可以退出。
21. 作为既有用户，我希望改名后原先选择的风格仍然生效，以便升级不会把我的设置重置成默认。
22. 作为维护者，我希望风格 id 与界面名一致（`synthwave` / 蒸汽梦核式），以便不再出现「蒸汽」被读成蒸汽朋克。
23. 作为维护者，我希望这套风格有静态守卫与端到端断言，以便下次改动不会再次把网格悄悄移出视口。

## Implementation Decisions

**范围与结构**

- 只改 synthwave 的样式作用域与模板；共享层只做三处最小增补：订阅页骨架的场景插槽、链接箭头图标开关、元信息图标开关。三处都是可选参数，不传时行为与现在完全一致。
- 场景复用既有的 sticky 假固定层，不引入第二种固定层实现；动画只挂场景子层，内容根容器保持无动画。
- 订阅页需要完整场景，因此订阅页骨架接受一个可选的场景节点，插在内容之前；其余风格不传，DOM 不变。
- 相关链接箭头改为图标元素，同时关闭基础样式里的文本箭头；元信息图标只在 synthwave 的订阅页条目上开启。
- 图标使用仓库已安装的本地图标库（`lucide-react`），不引入网络资源。运行期从 CDN 取图标会被现有 CSP 拦截，`img` 方式也无法继承文字颜色。
- 风格 id 由 `dreamcore` 改为 `synthwave`，界面名不变。持久化旧值在读取路径映射为新值、写回时落新值，用户选择不丢。

**场景（暗侧为基线）**

- 天空：`#24103f` → `#b01a5a` → `#ff8a4c` 的垂直渐变，铺满场景层。
- 扫描线：1px 线 / 3px 间隔 / 黑 alpha 0.10；静态；只存在于场景层，不覆盖正文。
- 落日：直径 `min(52vh, 480px)`；圆心位置维持现状（顶部 7%、水平中轴）；10 道条纹，上密下疏；色带 `#ffe14d` → `#ff9a3c` → `#ff2d95`；12s 上下浮动 10px。
- 网格：高度 95vh、`rotateX(52deg)`、`perspective(1600px)`、原点底部居中；底边抬到内容可视区下缘之上（约 136px 的窗口 chrome 补偿）；格距 72×56、线宽 2px、线色 `rgba(255,45,149,.55)`；平面自带地面底色 `#170a2a`；顶部 28% 渐隐；地平线为 2px 亮带 + 18px 辉光。
- 网格以 3.2s 周期向下滚动；减少动态效果与窗口不可见时停止。
- 场景层整体对辅助技术静默、不接收指针事件。

**卡片与文字**

- 暗侧卡面 `rgba(20,8,38,.62)` + `backdrop-filter: blur(18px) saturate(1.15)`；亮侧 `rgba(255,255,255,.62)` + 同一滤镜。
- 卡面作用于刊头、条目、概览底板、订阅页条目。概览底板为新增，内衬 12×16，与卡片同源。
- 暗侧：正文 `#f0dcff`、标题 `#ffe6ff`、次要文字 `#c9b7e0`、链接 `#ff8ad0`、accent `#ff2d95`、accent 上文字 `#1a0010`。次要文字由 `#b9a3d6` 上调，使毛玻璃压在落日最亮处时仍 ≥ 4.5。
- 亮侧：底 `#ffd6e8` → `#ffe6cc`、正文 `#3d0a2c`、标题 `#4a0736`、次要文字 `#8c3f6a`、链接 `#b0005a`、accent `#e0006e`。
- 圆角统一 16px；边框 1px 半透明品红。
- 导语保留左侧 3px accent 竖线与 8px 圆角，底色为 accent 12%。

**字体**

- 标题字族：Noto Sans SC / Microsoft YaHei。
- 刊头字族：JetBrains Mono → Consolas → Noto Sans SC；等宽只作用于拉丁与数字，中文仍落黑体。
- 刊头标题 28px、字距 0.02em、字体色→accent 的横向渐变、1px 描边；不做倾斜。
- 正文维持 14.5px / 1.8，字体栈不变。

**订阅页**

- 与阅读页同强度挂载完整场景。
- 封面 16/9、featured 21/9；不改变布局预设、列数与字段开关。
- 元信息加日历与源图标，12px，与文字同色，间距 4px；仅在 synthwave 生效。

**交互与系统**

- 悬停只加深外发光与边框亮度，取消基础层的 −2px 上浮。
- 场景动画纳入「窗口不可见时暂停」的载体清单；减少动态效果下静态。
- 不新增 IPC、持久化字段或插件契约变更，唯一的数据层改动是 id 迁移。

## Testing Decisions

**好测试的标准**

断言外部可观察行为：场景是否与视口相交、卡片合成底色上的文字是否达到对比度、订阅页是否真的挂了场景。不锁实现细节：不逐条断言 `transform` 的字面值，而是断言投影高度落在区间内、底边在视口内；不读源码文本去校验 CSS。

**测试缝隙（seams，按「尽量高、尽量少」排序）**

1. **静态样式守卫（既有缝隙，复用）**：新增 synthwave 组，锁 token 值、网格参数、卡面 alpha 与模糊半径、落日 mask 的停靠点数量、次要文字对最不利合成底的对比度 ≥ 4.5、悬停无位移、暂停清单包含 synthwave 的动画载体。
2. **端到端（既有缝隙，复用）**：阅读页与订阅页用例增加 synthwave 亮侧场景（现在只有暗侧）。新增「网格底边与视口相交」的几何断言，替换现有只看 CSS 可见性的断言——后者正是网格失踪却没被发现的原因。订阅页断言场景节点存在且可见。
3. **单元（既有缝隙，复用）**：注册表 16 变体、id 迁移的读写两条路径。
4. **截图归档（可选，需单独决定）**：现有归档只覆盖 nocturne；为 synthwave 新建基线会扩大需要逐字节维护的面，建议先不建，等风格稳定一轮后再定。

**先例**：newsprint90s 的守卫组与阅读页/订阅页断言的写法；nocturne 的对比度审计与截图归档流程。

## Out of Scope

- 山脊剪影（山影）。它与「太阳不动」的约束不相容，明确不做。
- 调整太阳位置使其压向地平线。
- 真实的 chrome 斜体字效（中文无斜体字形）。
- editorial / wabi 两个风格的体检。
- Retro 5（AGENTS 瘦身）。
- Mini 模式适配（Mini 不挂橘鸦风格）。
- 主题编辑器、ThemeTokens 接入。
- 引入字体文件或 webfont。
- 改动订阅页的布局预设与字段门控。

## Further Notes

- 已知取舍：0.62 毛玻璃压在落日最亮处，正文 6.83、标题 7.50、次要文字 4.72（调色后）；太阳被卡面糊成雾团是用户接受的结果，不再追求完整可见。
- 性能：6 个以上 `blur(18px)` 面叠在一条持续滚动的网格上，需真机验收滚动帧率。降级顺序为 18 → 12 → 只保留刊头与概览的模糊。
- 参考图仅存在于会话中，不作为仓库资产；原型样张在本地被忽略的目录，不入库。
- 改名部分已完成并验证：类型检查 0 错、单元 482 全过、端到端 119 全过、nocturne 归档 5 张逐字节一致。
- **实施期确定（2026-10-22，#41 / #34 review）**：以下三条本 SPEC 正文未写，施工时定下，均记录在 `docs/STYLE-WORKLOG.md` 的 synthwave 节。
  - 亮侧地面色 `#ffcadb`：共享透视网格平面的 `#170a2a` 是给暗侧地面的，亮侧沿用会出现「亮粉天空 → 近黑地面」的断层，且卡片压在网格区时 0.62 白卡合成出 `#a7a2ae` 中灰底（次要文字 2.78:1、链接 2.81:1，AA 不过）。亮侧只覆盖 `background-color`，几何仍归共享规则与订阅页补偿。
  - 亮侧扫描线 alpha `0.06`（本文「场景」段的 0.10 是暗侧基线）：日间不需要那么强的 CRT 压暗，0.10 会把字压灰。暗侧维持 0.10。
  - 焦点色未随调色板迁移改动：暗侧 `#b89aff`、亮侧 `#7c4dff`。本 SPEC 未规定焦点色，改它属于设计决策（焦点环是功能件而非装饰色），待单独裁决。
