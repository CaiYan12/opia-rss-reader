# SPEC：八风格订阅页头版 V2 丰富化

**日期**：2026-10-24（Asia/Shanghai）。
**状态**：本地成稿（经 `/to-spec` 指令固化）；未发布 GitHub、未立工票、未实施。立工票与开工均为独立阶段门，待用户明示。
**基线**：`codex/feed-masthead-int-20261024`，`fc423b7`。
**关系**：承接[八风格订阅页头版规格 SPEC #67](https://github.com/CaiYan12/opia-rss-reader/issues/67) 与[验收报告](FEED-MASTHEAD-ACCEPTANCE-2026-10-24.md)。V1 已全量交付并通过功能门，用户视觉反馈为「过于简陋干练、不足以体现风格」；本 V2 即对该反馈的设计回应。#67 保持 OPEN。

## Problem Statement

用户查看 V1 八风格订阅页头版后明确反馈：大部分风格的头版过于简陋干练，不能体现当前风格的视觉语言；以 y2k 为例，头版窗口没有展现阅读页头图已有的系统窗口标题、关闭按钮等拟真设计，设计细节不够丰富。用户要求在保持当前克制动效的前提下继续优化各风格头版系统。

V1 的信息结构（真实源名 + 「订阅源」引导词 + host，日期留在卡片）与主材质已被接受；问题不在信息，在表现力——头版与各自阅读页刊头/头图的设计词汇之间存在明显落差。

## Solution

确立参照系总原则：**订阅页头版 = 该风格刊头语言的「订阅源版」**——逐风格从自己阅读页刊头/头图的词汇库搬件，同一份报纸的不同版面；不为头版发明新词汇，不推倒 V1 已成立的排版与主材质，在其上叠加风格细节。

| 风格 | 施力 | V2 设计表现 |
| --- | --- | --- |
| y2k | 大补 | 铭牌升级为拟真系统窗口：顶部标题栏（真实订阅源名做窗口标题）+ `_ □ ×` 三钮（× 同阅读页）；铬字渐变、像素浮雕窗体保留 |
| nocturne | 大补 | 阅读页签名件**极光带**静帧搬入（文字之下、两端渐隐、零新增色相）；底边升级渐变发丝线；h1 补冷辉光静帧 |
| editorial | 大补 | **L 形裁切角标**（左上/右下）挂头版；host 行题注化（发丝短线前置） |
| newsprint90s | 大补 | **三栏报头**：左「订阅源」、中楷体源名、右 host，底对齐；窄窗回落居中堆叠 |
| folio | 适度 | **印章水印**落头版右侧；头版左右缘加朱丝栏竖线；居中排版与文武线、朱菱花押不动 |
| synthwave | 适度 | 卡面内**扫描线静纹**；host 行下霓虹辉光细线；共享场景层照旧在卡后跑 |
| pop | 微调 | h1 补印刷硬影（同阅读页值）；标题面板角落爆炸星点缀 |
| wabi | 不动 | V1 双层毛边纸 + 陶拓印已是工艺封面基准，零改动 |

视觉主记忆点逐风格一个签名件（y2k 窗口、nocturne 极光带、editorial 裁切角标、newsprint90s 三栏报头、folio 印章、synthwave 扫描线），支撑细节不超过两件，其余全部安静。

## User Stories

1. 作为读者，我希望每个风格的订阅页头版一眼可认出该风格的阅读页身份，以便订阅页与阅读页是同一份刊物的不同版面。
2. 作为读者，我希望头版仍呈现真实订阅源名称、「订阅源」引导词与 host，以便信息结构保持稳定。
3. 作为读者，我希望头版不出现任何日期，以便不把文章日期误读为整份订阅的期号。
4. 作为读者，我希望 V1 已成立的排版与主材质保留，以便 V2 是叠加细节而非推倒重来。
5. 作为读者，我希望头版装饰一律静帧，以便克制的动效边界不被突破。
6. 作为使用减少动态效果的读者，我希望所有签名件静态成立即可完整看到，以便不依赖动画。
7. 作为读者，我希望头版增高后首屏仍能瞥见列表第一张卡，以便头版不喧宾夺主。
8. 作为读者，我希望共享层零改动，以便阅读页、通用界面、Mini 与其他页面不受本轮影响。
9. 作为读者，我希望长订阅源名自然截断或折行，以便极端样本不破版。
10. 作为使用辅助技术的读者，我希望装饰件不进入焦点顺序、不产生重复朗读，以便语义保持一次且清楚。
11. 作为读者，我希望 120% 缩放与窄窗下头版细节仍成立，以便放大或小窗不出裁切与横向溢出。
12. 作为读者，我希望 y2k 头版是一扇拟真系统窗口，以便它继承阅读页的窗口拟真语言而非只剩铬字。
13. 作为读者，我希望 y2k 窗口标题使用真实订阅源名，以便每个订阅源都是自己的窗口而非复读固定文案。
14. 作为读者，我希望 y2k 的 × 钮与阅读页同款、`_ □` 呈未激活态，以便主次分明且不误导为可点控件。
15. 作为读者，我希望 nocturne 头版有阅读页同款的极光带，以便暗夜身份在订阅页同样在场。
16. 作为读者，我希望极光带永远绘制在文字之下，以便辉光不洗淡标题字形。
17. 作为读者，我希望极光带零新增色相，以便风格色板不扩张。
18. 作为读者，我希望 nocturne 头版底边为渐变发丝线、标题有冷辉光，以便签名件之外仍有同语言的支撑细节。
19. 作为读者，我希望 editorial 头版有 L 形裁切角标，以便杂志印刷的裁切隐喻在场。
20. 作为读者，我希望 editorial 的 host 行对齐题注语言，以便次级信息有自己的角色形态。
21. 作为读者，我希望 editorial 不虚构栏目序号，以便编号只出现在真实序列上。
22. 作为读者，我希望 newsprint90s 头版采用三栏报头，以便老报纸报头的两侧小字格局成立。
23. 作为读者，我希望楷体源名字距向阅读页报头看齐，以便报头字性格一致。
24. 作为读者，我希望 newsprint90s 窄窗回落为居中堆叠，以便小窗仍自然成版。
25. 作为读者，我希望 folio 头版有印章水印与朱丝栏，以便信笺纸感身份完整而不只靠文武线。
26. 作为读者，我希望 synthwave 头版卡面内有扫描线与霓虹辉光细线，以便毛玻璃卡自身也有 CRT 身份而非只靠背后场景。
27. 作为读者，我希望 pop 标题有印刷硬影与爆炸星点缀，以便与阅读页标题语言一致。
28. 作为读者，我希望 wabi 头版保持不动，以便已成立的工艺封面基准不被扰动。
29. 作为读者，我希望各风格改动只落在本风格作用域内，以便已封版风格的其他部分保持冻结。
30. 作为用户，我希望定向 E2E 与静态守卫同步更新并全量验证，以便回归有硬证据。
31. 作为用户，我希望拿到 headless 亮暗截图逐风格复看，以便视觉认可有依据。
32. 作为用户，我希望实现状态、功能验证与我的视觉认可分开记录，以便测试通过不被写成审美已认可。
33. 作为用户，我希望 SPEC、工票、实施均为独立阶段门，未经明示不推进，以便节奏由我控制。

## Implementation Decisions

### 与 V1 的关系与边界

- 本轮只动订阅页头版；各风格已封版的其他部分冻结。V1 信息结构（源名 + 「订阅源」 + host，无日期）不动，已成立的主材质不动，V2 为叠加。
- 改动落点仅限：各风格订阅页 craft 模板、样式表中各风格自己的段落、对应守卫与测试。共享骨架、共享场景、通用界面零改动。
- 高度软规则：头版允许因补件适度增高，但订阅页首屏仍应瞥见列表第一张卡；不设逐风格像素上限，以验收截图裁定。
- 静帧纪律：头版本体零新增 animation / transition。从阅读页搬来的签名件取静帧——nocturne 极光带取既有「减少动态」钉定透明度（0.81 / 0.76），不新写关键帧。
- 构成色如需硬编码，遵循仓库标准必带注释；nocturne 等签名件零新增色相（取自既有变量）。

### 逐风格裁定

- **y2k**：标题栏必须是真实 DOM 元素（伪元素无法承载逐订阅源动态文本），整体 aria-hidden，长源名 `nowrap + text-overflow ellipsis`；标题文案形态 `<源名>.EXE — 运行中`；`_ □ ×` 三钮中 × 用阅读页同款 on-accent 底，`_ □` 用 muted 未激活态；不加状态栏。铬字渐变 h1、2px 浮雕边、inset 高光、硬影、monospace domain 全部保留。
- **nocturne**：极光带为头版容器两个伪元素，z-index 必须为 -1（既有教训：0 层会被绘制在非定位正文文字之上洗淡字形）；两端 mask 渐隐；四色取自既有极光变量；底边框改用阅读页栏目条的渐变发丝线技法；h1 冷辉光为双层 drop-shadow 静帧。
- **editorial**：裁切角标为头版容器两个 24×24 L 形角线（左上/右下），aria-hidden；host 行前置 24px 发丝短线对齐题注语言；刻意不搬栏目序号——订阅源没有真实序号语义，编号即造假信息。
- **newsprint90s**：头版改三栏 grid（`1fr auto 1fr`，底对齐）：左栏「订阅源」kicker、中栏楷体源名（字距向阅读页报头 6px 量级看齐，按 clamp 实际收放）、右栏 host；窄窗（同阅读页报头断点）回落居中堆叠；上下框线与 4px double 底线保留。
- **folio**：印章水印为 72×72 SVG data-URI，rotate -8deg、opacity 0.12、mix-blend multiply，置于头版右侧，aria-hidden；朱丝栏为头版左右缘 1px 绯色 hard-stop 渐变竖线；居中排版、文武线、朱菱花押不动。
- **synthwave**：卡面内扫描线为低透明度 repeating-gradient 静纹；host 行下霓虹辉光细线（1–2px accent 渐变 + 静态辉光，echo 阅读页地平线辉光）；共享场景层（太阳/网格）照旧，不因卡内纹理调整场景。
- **pop**：h1 补 `3px 3px 0` 印刷硬影（与阅读页 h1 同值）；标题面板 h1 角落加爆炸星 SVG（阅读页同款白色星形，aria-hidden）；面板拼贴、Ben-Day 色带、贴纸 kicker 不动。
- **wabi**：零改动。

### 术语与记录

- GLOSSARY 不新增词条：「订阅页头版」既有定义已预留各风格自由度；无不可逆架构决定，无需 ADR。
- 验收报告沿用「实现状态 / 功能验证 / 设计自评 / 用户视觉认可」分栏；用户未复看认可前最后一栏保持待确认。

## Testing Decisions

### 测试缝

全部复用既有缝，零新缝：

1. **渲染 E2E**（既有 per-style 头版 spec 与预设 spec 为先例）：断言外部可见行为——签名件存在且可见、层级正确（极光带在文字之下）、长源名截断、三栏底对齐、窄窗回落形态、未激活钮态、负对照（wabi 头版 DOM 不变、各风格间不串件）。
2. **静态守卫单测**（按风格组更新既有守卫）：静帧纪律（新增装饰段无 animation/transition）、nocturne z-index -1 与色相集合不变量、构成色注释标准等。
3. **全量 verify** 作为最终门（单测 + E2E + 既有归档一致性）。
4. **headless 亮暗截图**逐风格供用户视觉复看。

好测试检查实际渲染行为（元素在、可见、在正确层级、被正确截断、变体差异成立），不把「类名或背景字符串存在」当作视觉已成立；对比度、溢出与截断用真实渲染取证。测试边界已在设计确认轮经用户确认（「确认」覆盖清单含验证方案）。
