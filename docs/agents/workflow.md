# 工作流阶段门

本仓库按阶段推进；每一阶段的产物形状不同。**用户没有明确说进入下一阶段时，只交当前阶段的产物。**

| 阶段 | 允许的产物 | 不做什么 |
|---|---|---|
| 体检 audit | 测量值、截图、根因、候选改法（文字） | 不编号成票据、不给推荐组合、不写 SPEC |
| grilling | 一轮问题 + 每题推荐答案 | 不写文件；等回答再进下一轮 |
| SPEC | 问题 / 方案 / 用户故事 / 实现决定 / 测试决定 / 范围外 | 不发布 issue（发布是单独的门） |
| TICKETS | 纵切票 + 阻断边 + 粒度确认 | 不开始实现 |
| implement | 按依赖图逐票：TDD → 定向测试 → 提交 → 合并 | 不跳票、不预写下一票 |
| 验收 | 全量 verify、前后证据、真机验收 | 不自行 push / 开 PR / 发行 |

## 外部写操作

issue 创建、PR、push、tag、发行各自需要用户明确的动词；不要用「已批准方案」推断。

## 验证

未实际运行的验证不得声称通过；写错的数字要改回并注明。
