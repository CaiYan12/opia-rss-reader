## 2. 定位：破晓

亮侧不是「白色版星空」，也不是纯纸面。它是同一「暗夜精修式」的**破晓**：夜将尽、晨雾未散、早霞初起。三点保持不变：

1. **排版纪律**：与暗侧同一套发丝线、字号层级、克制的正文阅读带。
2. **光的语言**：暗侧是星尘与极光；亮侧是晨雾、晨光弧、早霞与青绿晨气。
3. **亮色为主**：页面整体仍是亮的、可长时间阅读的；激进色在场景与装饰，不在正文。

与其余亮侧风格的分工：folio/newsprint 是纸，editorial 是杂志白，wabi 是手作暖灰；nocturne-light 是**破晓的天空**——冷底暖霞、曲线构造、晨雾细节，占一个无人使用的生态位。

## 3. 调色

### 3.1 角色

| 角色 | 方向 | 候选锚点（实施时按 AA/截图校准，非锁定值） |
|---|---|---|
| 页面底 | 仍为亮色；浅长春花/淡薰衣草只做天空底与右上 | `#fbfbfc` 为底，场景冷色 `#eef0fb / #e9ebff` |
| 早霞 | 左下/左侧；珊瑚 → 杏 → 蜜桃 → 晨金 | `#ff8a6b / #ffb27a / #ffd0b0 / #ffd27a` |
| 玫瑰 | 冷暖过渡与晨云 | `#f3a6b8` |
| 绿 | 青瓷/鼠尾草做雾与浅层；饱和青绿/翡翠只放曲线边缘与少量细节 | `#a7c8b6 / #2f7f78 / #2f7d5f` |
| 文字 | 墨色体系保持不变 | `#17181d / #3a3b44` |
| 交互 accent | **保持靛蓝**：链接、焦点、概览序号 | `#4f5ed8 / #4051c9` |
| muted / 导语 | 本轮修到 AA；实施校准 | `--jy-muted #5f6069`、`--jy-lead-text #5b5c65`（`#66676f` 在 480 最暗可达面只有 4.47；实施值实测 muted 5.02–5.07 / hover 5.33、导语 4.85–5.20） |
| 订阅卡 | 晨雾白毛玻璃 | `rgba(255,255,255,0.7)` + `blur(12–18px)` |

### 3.2 约束

- **accent 不漂**：靛蓝是夜留给破晓的冷色，也是全风格的交互身份；绿与晨霞只做装饰。不改成霓虹、不改成荧光绿/酸橙。
- **亮色为主**：页面整体保持亮；激进体现在曲线/晨霞的饱和度与层积，不把页面做成暗底或整屏高饱和大色块。
- **AA 优先**：正文列、卡片、导语、概览、焦点环按现有门槛（文字 4.5、非文本 UI 3）；亮侧的 muted 4.32 必须在本轮修掉。
- **零新增色相纪律放宽但可控**：本轮允许新增晨霞/绿/玫瑰；每个新色必须注明取色来源与对实际背景的 WCAG 值，防以后随手加色。

## 4. 曲线与构图

### 4.1 曲线语言（已选 a）

**晨光弧 + 流云带 + 等高线细节**：

- 一条**低的晨光弧/光带**，不是具象日轮（避开 y2k 的太阳/地平网格与 synthwave 的落日语义）。
- 2–3 条**宽流云曲线**，有方向、有层积、有透叠；曲线是背景的结构，不是随机装饰。
- **细等高线/发丝线细节**：沿曲线走势的精密细线，承担「精修」；细节密度在边缘、刊头、卡片处最高，正文列最低。

排除：同心日出弧（与 y2k/synthwave 撞语义）、纯等高线地形（早霞色面会弱）、手绘/飘带自由曲线（与 wabi 的手作、folio 的纸面语言冲突，且需新增图形资产）。

### 4.2 构图

- **晨光从左侧/左下升起**，曲线向右上扫；冷色（浅长春花/薰衣草/青绿）退到右上，暖霞（珊瑚/杏/蜜桃/晨金）聚在左下。
- **正文列中心留浅雾可读面**：曲线全幅铺开，但正文列上覆一层很浅的雾白/薰衣草渐变（veil），曲线透过雾仍可见；激进色、细等高线、晨露点集中在两侧、顶部、刊头和卡片。
- **订阅页同构**：订阅页头版与卡片列表使用同一片破晓，滚动时背景固定、内容在其上滑过（沿用 `.juya-scene` 的视口锚定）。

### 4.3 细节

- 细等高线、晨露点、雾面颗粒、柔光带；不画飞鸟、太阳脸或具象景观。
- 「丰富」不等于满：细节不能压在正文列的字后抢对比度；正文列的细节密度最低。
- 所有细节为 `aria-hidden` 装饰层，不拦截交互。

## 6. 动效与降级

- **极慢晨雾漂移（约 120s）+ 曲线静止**；晨露/细线不闪、不做亮星式 twinkle。
- 亮侧死场景的 96s dust / 5s stars 动画由新的晨雾/曲线场景替换；`[data-app-hidden]` 暂停清单必须覆盖亮侧新载体。
- `prefers-reduced-motion: reduce` 下晨雾完全静止，保留静态晨光/细节；动画只挂场景子层，`.juya-root` 永无 animation。
- 性能：晨雾用静态渐变/遮罩为主，漂移只动合成器友好属性；毛玻璃的 `backdrop-filter` 需 perf probe/真实窗口复核（与暗侧同一待办口径）。
